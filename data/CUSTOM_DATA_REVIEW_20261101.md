# Tambah Data dan dialog aplikasi — Paket 29

Kotoba dan Kanji dapat ditambah, diedit dan dihapus secara lokal. Form level N5/N4 terpisah dari preferensi belajar. Data masuk ke menu Kotoba/Kanji pada level yang dipilih. Form dan daftar buatan pengguna memiliki tab jenis data, pencarian dan filter level. Kotoba membutuhkan kata, romaji dan arti; kana opsional. Kanji membutuhkan satu karakter Han dan arti; on/kun opsional, beberapa bacaan dapat dipisahkan slash/koma. Satu contoh kata beserta kana dan arti, jembatan ingatan, radikal dan jumlah guratan dapat diisi bila diketahui. Contoh harus memuat karakter tersebut. Ini isian manual pengguna, bukan hasil verifikasi bahasa otomatis.

Duplikat Kotoba dicek pada level yang sama terhadap data bawaan dan buatan pengguna, termasuk alias, normalisasi Unicode dan variasi spasi. Duplikat karakter Kanji dicek lintas level agar tidak mengulang karakter bawaan yang sudah ada. Edit mengabaikan rekornya sendiri saat cek duplikat. ID lama custom-N dipertahankan saat penulisan pertama agar favorit tidak berpindah saat data dihapus. Entri baru mendapat ID mandiri. Edit menggabungkan properti lama, bukan membuang metadata tambahan.

Kotoba tetap memakai gaku-ui-data; Kanji memakai gaku-ui-kanji. JSON rusak/tidak sesuai bentuk tidak ditimpa. Penulisan gagal tidak menghapus data di memori. Sebelum edit/hapus, data terbaru dibaca dan snapshot rekornya dibandingkan; perubahan rekornya dari tab lain ditolak agar tidak tertimpa. Penambahan rekaman lain setelah dialog dibuka dipertahankan. LocalStorage bukan transaksi lintas-tab. Menghapus hanya menyentuh record buatan pengguna, tidak menghapus materi bawaan, audio atau seluruh Riwayat. Hapus memiliki konfirmasi aplikasi dan Batal/Escape; tidak dapat dipulihkan setelah dikonfirmasi. Penambahan/edit mencatat aktivitas dengan level yang dipilih pada Riwayat.

Kanji buatan pengguna ditandai Buatanmu, dapat dicari, dibuka, dan difilter kategori; tetap muncul pada cakupan awal N4 agar bisa ditemukan. Tidak dimasukkan ke soal Quiz Kanji bawaan karena kelengkapan/keakuratan isian tidak dijamin. Detail memakai escape HTML dan argumen audio aman. On/kun kosong tidak menyebabkan crash; tanpa contoh ditampilkan pesan pendek. Edit/hapus tersedia di Tambah Data.

Dua filter Riwayat (jenis aktivitas dan level) serta seluruh pilihan level Tambah Data memakai dialog pilihan aplikasi yang sama dengan menu belajar, bukan pemilih Android. Tombol tutup, Escape dan Back membatalkan pilihan; pilihan yang disimpan memperbarui caption tombol bahkan bila form tidak dirender ulang, sehingga draf isian tetap ada saat memilih level. Jenis data memakai dua tombol tab. Form tidak memunculkan pesan validasi bawaan browser: kesalahan ditampilkan melalui toast aplikasi.

Validasi: 53 berkas tes termasuk regresi paket 28, CRUD dua jenis, level, duplikat, ID lama, escaping, bacaan kosong, contoh tidak lengkap, kegagalan storage, JSON rusak, hapus dengan data baru dan pembaruan caption picker. Browser pada iframe 390px diperiksa menggunakan localStorage in-memory khusus fixture: simpan Kotoba N4, simpan Kanji N5 tanpa bacaan, Batal hapus, dialog jenis/level Riwayat, filter N4 satu dari dua aktivitas. Uji ini tidak mengubah data browser pengguna; belum Android fisik. Paket kumulatif 1–28 termasuk 144 audio Kaiwa N4. Installer memeriksa hash, mencadangkan, menjalankan seluruh tes dan rollback jika gagal. Tidak commit/push/deploy otomatis.
